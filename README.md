# Vocably

Ôn từ vựng TOEIC với FSRS — offline trên trình duyệt.

## Chạy

```bash
npm install
npm run dev
```

→ http://localhost:5173

## Tài khoản

| Vai trò | Cách dùng |
|---------|-----------|
| **Đăng ký** | Bắt buộc trước khi đăng nhập |
| **Admin mặc định** | `admin@vocably.local` / `admin123` |
| **Khách** | Demo 50 từ, không thêm từ / không xuất CSV |
| **User** | Full kho từ, thêm/sửa/import CSV |
| **Admin** | User + xuất CSV + trang `/admin` quản lý tài khoản |

## Scripts

- `npm run dev` — port **5173**
- `npm run build` / `preview` / `typecheck`
